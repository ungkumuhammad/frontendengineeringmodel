Tank geometry & levels

PGS 12: max fill ≥ 0.5 m below the top of the shell (1999 §6.4.1.6); separate high-level protection and independent overfill trip (2025 M17/M18); in-tank pumps, no connections below liquid level (M10/M30), so the heel is set by pump submergence. Response times and the heel are placeholders — PGS 12 sets no values; take them from the HAZOP/SIL study and the pump vendor.

Heel 1.5 m + top margin 3.1 m reproduce TEPSA's net/nominal ratio (84.3 %). The split is a calibration, not a disclosed level schedule.

Plot area reference

Plot required = reference plot × design net capacity ÷ reference tank size (linear). Reference: 3.7 ha for a 60 kt tank including the jetty, with the jetty 500 m from the tank.

Utilities & boil-off

Pass-through at cost + admin mark-up. Same basis applied to every operator at the same site.

CAPEX basis

Default reference = TEPSA quote: €185M storage for 40,000 t net + €20M jetty (HAROPA, Le Havre). Scaling: CAPEX ∝ sizeexponent.
